# ShashiKanth B — Portfolio

Static site (HTML + CSS + JS). No build step.

## Run
Open `index.html`, or deploy the folder as-is to Vercel / Netlify / GitHub Pages.

## Edit content
Everything is in `js/data.js`:
- `projects[].url`        -> where the project card opens (empty = not clickable)
- `certifications[].url`  -> direct certificate link (empty = opens issuer site)
- `person.linkedin / github` -> add your profile URLs to show those buttons
- `assets/ShashiKanthB_Resume.pdf` -> replace to update the résumé download
